# v0.52.0 Release Notes

Artifact v0.52.0 is the Toolset Consolidation release: fewer, deeper tools.
The 62 effects become 27 effects with modes, an effect layer is an ordered
stack of effects, every basic a cover needs is reachable from Layers, and the
3D Scene and Environment Map nodes fold into one 3D Object.

This release changes the document format and the tool catalog. Existing
documents migrate on load and render the same: every golden render fixture is
unchanged, and the 3D scene migration matched pixel for pixel in a WebGL
check. It adds no new visual direction and does not change editor chrome.

Document schema changed as described below. Graph traversal follows the new
3D Object ports; renderer/export output of existing documents, thumbnail
scheduling, AI scope, package export, and font policy remain unchanged.

## Compatibility

Stored documents and share links move from schema 6 to schema 19 when this
version opens them. **Builds before v0.52.0 cannot open schema 7 or later
documents or share links** and show "Unsupported document schema version".
Documents and links saved by v0.52.0 need v0.52.0 or later.

## Highlights

- Effect stacks: one effect layer holds an ordered list of effects, each with
  its own on/off switch, instead of every parameter of every effect. An effect
  layer can apply to everything below it or only to the layer directly below.
- 27 effects with modes replace 62: for example Color Filter (sepia, infrared,
  bleach, solarize, mixer), Gradient Map (duo, tri, split), Posterize (levels,
  dither, cutoff, palette), Glow (bloom, neon), Halftone (dots, lines,
  stochastic), Line Glitch, Compression, Displace, Lens, Symmetry, Blur, and
  Pixelate. Old effect names still find their effect in Add Library search.
- New cover basics in Layers: an Adjust effect (brightness, contrast,
  saturation, hue, exposure, temperature, invert), Sharpen, and a Shadow
  effect (drop or grime) that replaces the Grime Shadow node; linear and
  radial gradient fills; text tracking, leading, outline, and shadow; and
  "Clip to layer below" on any content layer.
- One 3D Object: a built-in shape or an imported GLB model, switched with its
  Source control. Turning on scene lighting adds a light rig, exposure, an
  EXR/HDR environment map, and material and environment inputs. Dropping an
  environment map applies it to the selected 3D Object.
- A shorter Add Library: Nodes browses 45 items (from 105) and Layers 36 (from
  88). Presets of noise, shape pattern, and repeat sources are searchable and
  sit in each source's inspector as a starting point; recipes insert their
  wired node graph in one action.
- Every graph node kind can be duplicated (also with `⌘D`) and hidden, except
  a material, whose settings its consumers read. Every library item has its
  own description, and Nodes starts loading when you reach for it.

## Scope Boundaries

- Included: the Toolset Consolidation plan, steps 1-5
  ([`v0.52`](../version-plans/v0.52.md)): broken-action fixes, the effect stack
  (schema 7), catalog merges (schemas 8-17), Layers capabilities and the Shadow
  effect (schema 18), and sources and 3D (schema 19).
- Included: Array is now named Shape Pattern.
- Included: a Firefox fix that defers media query state updates out of style
  flushes ([#475](https://github.com/shchilkin/artifact/pull/475)).
- Included: the CI, staging, and release workflows run on `ubuntu-24.04`,
  because Playwright cannot install browsers on the `ubuntu-26.04` image
  `ubuntu-latest` can now resolve to.
- Removed: the 3D Scene, Environment Map, and Grime Shadow node kinds, which
  migrate into a 3D Object and a Shadow effect layer.
- Deferred: one control grammar across menus, rows, headers, and controls
  ([Editor Polish](../version-plans/editor-polish.md)), and AI-Assisted
  Creation.
- Deferred: the mobile task-flow layout.

## Accepted Risks

- Builds before v0.52.0 cannot open documents or share links saved by v0.52.0.
- A scene-lit 3D Object renders full frame over its backdrop, so its opacity
  and blend do not apply; the inspector hides its Style section while scene
  lighting is on. This keeps the former 3D Scene node's output.
- A material node cannot be hidden, because its consumers read its settings
  instead of rendering it.
- The 3D Object inspector has two "Material" controls: the shape's colors in
  Content and the scene's Original, Clay, and Unlit choice in Lighting.
- Before-render JavaScript grew on Projects (226.3 to 234.9 KiB) and the
  style guide (367.0 to 377.6 KiB), and the home hero after render by 0.9 KiB,
  because loading a stored document runs thirteen new frozen migration steps
  and the effect catalog is larger. Their route-loading budgets moved to 240,
  380, and +190 KiB. Loading the migration chain only for older documents is a
  follow-up.
- Eight text-rendering unit tests in `layerStyles.test.ts` and
  `graphRender.test.ts` fail on the `ubuntu26/20261018.50` runner image and pass
  on `ubuntu26/20261025.179` and `ubuntu-24.04`, because they rely on what the
  machine offers for text. The pinned runner avoids this; the tests still need
  to stop depending on it.
- Golden pixel hashes are only valid inside the pinned Playwright container,
  because text and emoji rasterize differently per operating system.
- The Undo tooltip says "Cmd+Z" on every platform, including Windows and
  Linux, where the shortcut is Ctrl+Z.
