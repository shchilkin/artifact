# v0.48.0 Release Notes

Artifact v0.48.0 is the UI Conformance And Legacy Removal release. It completes
the bounded full visible-UI rewrite by giving Artifact and Backoffice one
enforceable Foundation contract while preserving their distinct Product
Themes.

This release turns the migration inventory into an executable two-product gate
and removes the compatibility surface only after every registered caller has a
canonical replacement.

Document schema, graph traversal, renderer/export behavior, render signatures,
thumbnail scheduling and caches, pointer geometry, persistence, auth, AI scope,
package export, and font policy remain unchanged.

## Highlights

- Added shared theme-aware browser assertions for every Foundation Matrix
  primitive and representative command, field, feedback, and overlay states in
  Artifact and Backoffice.
- Made Backoffice desktop/mobile conformance a required CI browser job alongside
  Artifact's Chromium, Firefox, and WebKit coverage.
- Migrated the final Artifact callers, deleted seven zero-caller compatibility
  files and their bounded selectors, and converted the finite registry into a
  no-reintroduction contract.

## Scope Boundaries

- Included: shared Foundation anatomy, computed theme-token conformance,
  responsive geometry, keyboard/focus, reduced-motion, and accessibility proof
  across both products.
- Included: removal and permanent prohibition of the registered legacy imports,
  aliases, selectors, token references, and file paths.
- Deferred: application-shell ownership, route CSS, hydration, prerendering,
  dependency activation, and JavaScript/CSS budgets to v0.49.
- Deferred: AI-Assisted Creation to v0.50, after the v0.49 gate closes.

## Validation

Local validation passed during release prep on 2026-07-26:

- `npm run release:verify -- --version 0.48.0`
- `npm run check`
- `npm run build`
- `npm run test:browser:ui-conformance`
- `npm run test:browser:release`

The full browser gate scheduled 554 scenarios across Artifact Chromium,
Firefox, WebKit, mobile Chromium, mobile WebKit, and Backoffice desktop/mobile
Chromium: 501 passed on the first attempt, 3 passed through the configured
retry, and 50 were intentional skips. Focused no-retry reruns then passed the
Chromium 3D render/export and WebKit Pixelate scenarios; the capability-gated
WebKit 3D scenario skipped as designed.

Performance notes:

- `npm run perf:node-editor` was not required because this release does not
  change graph traversal, renderer paths, render signatures, thumbnail queues,
  pointer geometry, or node-editor interaction hot paths.

## Manual QA

- Reviewed the live Artifact and Backoffice style-guide surfaces at 1440-pixel
  desktop and 390-pixel mobile widths. Artifact preserved its token hierarchy
  and single-column mobile flow; Backoffice preserved readable operational,
  status, error, focus, and mobile command states without page overflow.
- Verified the migrated SearchField geometry and canonical icon action, plus
  the contract guard that fails on any removed file or legacy contract.

## Accepted Risks

- Conformance covers representative live surfaces, semantics, computed theme
  tokens, keyboard focus, geometry, responsive overflow, reduced motion, and
  the supported browser matrix; it is not a complete pixel visual-regression
  suite or WCAG certification.
- The build retains the large Three.js vendor-chunk warning. v0.49 owns the
  production route/loading matrix and measurable JavaScript/CSS budgets instead
  of treating a standalone chunk warning as sufficient evidence.
- Browser logs retain existing blank-frame fallback, intentional missing-route,
  and Vite development-server dependency-reload diagnostics. Production-preview
  navigation passed, and these messages are accepted only while every
  release-gate scenario completes successfully.
- The full gate needed three configured retries: one Chromium 3D startup and
  two WebKit startup/teardown scenarios. Focused no-retry reruns passed the two
  runnable scenarios; the WebKit 3D case returned its intended capability skip.
- `npm ci` reports 17 inherited dependency advisories (3 low, 4 moderate, and
  10 high). This release changes no dependency versions; reachability and
  remediation remain in the dedicated trace-backed dependency track.
