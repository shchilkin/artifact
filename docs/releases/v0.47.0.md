# v0.47.0 Release Notes

Artifact v0.47.0 is the Canvas Chrome release. It gives the graph workspace,
artwork preview, node previews, galleries, and 3D viewports one legible,
accessible visual language while preserving the creative systems underneath.

This release rewrites workspace framing, feedback, command, focus, and
direct-manipulation chrome. It deliberately leaves final compatibility cleanup
and zero-caller conformance to v0.48.

Document schema, graph traversal, renderer/export behavior, render signatures,
thumbnail scheduling and caches, pointer geometry, camera-state ownership,
persistence, AI scope, package export, and font policy remain unchanged.

## Highlights

- Migrated graph workspace, node housing, ports, output paths, areas, viewport
  controls, Add Library drop feedback, and empty graph states onto source-owned
  Artifact patterns.
- Added explicit preview loading, empty, error, recovery, selection, locked,
  hidden, and keyboard-operable direct-manipulation states while keeping
  transparent output transparent.
- Unified thumbnail and gallery loading, ready, failed, retry, selection, and
  expanded-preview framing with preserved aspect sizing and last-good frames.
- Migrated primitive, model, environment, and scene viewport framing, camera
  affordances, unavailable states, and recovery actions without changing live
  camera or export ownership.

## Scope Boundaries

- Included: graph, node, edge, port, area, CanvasPreview, thumbnail, gallery,
  primitive, model, environment, and scene viewport chrome.
- Included: deterministic style-guide specimens plus desktop, mobile,
  keyboard, cross-browser, renderer-boundary, and performance coverage.
- Deferred: compatibility aliases, legacy selector removal, and final
  cross-app conformance to v0.48.
- Deferred: new AI-assisted creation and the accepted React Router/chunk
  boundary follow-up to v0.49.

## Validation

Local validation passed during release prep on 2026-07-25:

- `npm run release:verify -- --version 0.47.0`
- `npm run check`
- `npm run build`
- `PLAYWRIGHT_WEB_SERVER_PORT=43015 npm run test:browser:release`
- `PERF_PORT=43017 npm run perf:node-editor`

The full browser gate passed with `503 passed, 51 skipped` across Chromium,
Firefox, WebKit, mobile Chromium, mobile WebKit, and Backoffice desktop/mobile
Chromium.

Performance notes:

- `npm run perf:node-editor` passed. Drag, effect-control, and graph-pan
  interactions produced no long tasks or thumbnail/render work; their p95 frame
  times were 17.0-17.5 ms against the preferred 50 ms budget.

## Manual QA

- Reviewed the deterministic desktop and mobile Canvas Chrome specimens for
  node structure, artwork preview, gallery framing, and primitive/3D camera
  ownership.
- Verified the live empty graph action, invalid Add Library drop feedback,
  preview recovery, keyboard move/scale/rotate handles, 44-pixel gallery
  actions, and missing-model recovery across the focused browser coverage.

## Accepted Risks

- Conformance covers representative live surfaces, semantics, keyboard focus,
  geometry, responsive overflow, and the supported browser matrix; it is not a
  complete visual-regression suite or WCAG certification.
- Compatibility wrappers and legacy aliases remain until the v0.48 zero-caller
  conformance gate.
- The build retains 11 inherited Fast Refresh warnings and the large Three.js
  vendor-chunk warning. The accepted router/chunk follow-up is documented
  separately and does not block this visual migration.
- Browser logs retain existing blank-frame fallback and development-only
  missing-route diagnostics; no scenario failed in the final release gate.
