# v0.51.0 Release Notes

Artifact v0.51.0 is the Core Reset release. The editor engine now has one
topology source, a node-kind registry, a declared effect parameter schema, and
one command path for document edits, so a new node kind or effect parameter is
a local change. It also ships the Editor Polish Patch fixes: Nodes opens
readable, editor actions give visible and truthful feedback, and Layers tree
actions work from a clicked name, after Undo, and on touch.

This release rebuilds engine internals while keeping rendered output the same,
except for one background fix in Nodes. It adds no new node kinds, effects,
presets, or design direction.

Document schema and graph storage changed as described below; existing
documents migrate on load. Graph traversal, renderer/export output, thumbnail
scheduling, AI scope, package export, and font policy remain unchanged apart
from the fixes listed here.

## Compatibility

Stored documents and share links move from schema 3 to schema 6 when this
version opens them. **Builds before v0.51.0 cannot open schema 4 or later
documents or share links** and show "Unsupported document schema version".
Documents and links saved by v0.51.0 need v0.51.0 or later.

## Highlights

- One topology source: every document has a graph, and Layers and Nodes read
  the same structure. Entering Nodes no longer loses the background.
- Engine registries: each node kind has its own model, renderer, UI, and
  inspector modules registered in one place, and the 110 effect parameters and
  61 render effects are declared once in a schema that drives defaults, backend
  choice, inspector controls, preset splitting, and docs ranges.
- Truthful undo: every durable edit is a named command with its own history
  policy. Layers visibility, area, rename, and image replace, and Nodes
  connect, disconnect, move, layout, and area edits are one undo step each
  instead of being merged by a 400 ms debounce. A discrete action right after a
  gesture keeps the gesture's undo step, and Undo during a gesture returns to
  where it started.
- Nodes opens readable: nodes without a stored position are laid out before
  the first paint, overlapping cards move below the rest while cards that
  overlap nothing stay where they were, and the graph is fitted once. Edit in
  Nodes selects and centers its node. Metrics and Debug toolbar controls appear
  only with `?debug` or `?perf=1`.
- Layers tree actions work where you expect: Delete, arrow keys, F2, and
  Shift+F10 work after clicking a row's name; Undo, Redo, and inspector edits
  clear a stale tree status; a graph-only node's inspector offers Edit in Nodes;
  and on touch, row actions stay visible with 44 px hit areas.
- Visible feedback: a typed value outside a slider's range shows the limit it
  was clamped to ("Max 100%"); effect help opens on click, Enter, or Space and
  sits beside its row; export keeps a fixed width while "Exporting…", announces
  the downloaded file name, and keeps an error visible with Retry; an
  unreadable `?doc` link says so; and a canvas render error offers Undo and
  Retry without a reload.
- A steady command bar: the undo count moved into the Undo tooltip, so no
  command-bar button moves after the first edit. Destructive confirmations use
  a filled danger button, and the Projects sheet says "Save current canvas" and
  "New blank canvas".

## Fixes

- The RGB Split preset showed two sliders for one field; it now shows one.
- Effect docs ranges match the controls; nine stated a different range, for
  example Glitch 0–100 where the slider stops at 24.
- Dropping an environment node onto a connection feeds the node's input instead
  of a port it ignores.
- The legacy effect split no longer breaks graph edges, and RGB Split is no
  longer applied twice.
- Hidden file inputs no longer take Tab stops, sheets respect reduced motion,
  and the mobile viewport, theme color, and color scheme match the app surface.
- Editor strings no longer contain internal notes or version labels, and
  in-progress labels end in "…".

## Accepted Risks

- Builds before v0.51.0 cannot open documents or share links saved by v0.51.0.
- When the browser cannot store a font, model, or environment payload, the
  payload is dropped from the current document without an undo entry. This is
  the existing storage-failure fallback and the one recorded exception to "no
  silent write changes visible state".
- Golden pixel hashes are only valid inside the pinned Playwright container,
  because text and emoji rasterize differently per operating system.
- The Undo tooltip says "Cmd+Z" on every platform, including Windows and
  Linux, where the shortcut is Ctrl+Z.
- Nodes area frames follow their member nodes and can overlap each other after
  placement. Frames sit behind the cards, so every card stays clickable.
- Home after render (187.3 of 188 KiB), Projects (226.3 of 230 KiB), and the
  style guide (367.0 of 370 KiB) are close to their JavaScript budgets; the
  next route-level addition there needs a reviewed contract update.
- Grouping rows into a new merge, wiring side inputs, and creating fan-out
  remain available only in Nodes.

## Known Warnings

- Transitive dependencies with security advisories were updated without major
  upgrades, including `proxy-addr` (critical), `body-parser`, `compression`,
  `zod`, and `vite`. `npm audit` still reports four moderate or low advisories
  in Vitest and Fallow development tooling that need major upgrades; neither
  ships in the app.
- The showcase-to-editor smoke needed one retry, on Firefox this time (the
  page stayed on `/showcase` after a tile click). It needed a retry on WebKit
  in v0.49.0 and v0.50.0 and is tracked in #435.
- React Router 7.18 prints v8 future-flag warnings during the build, Vite
  reports that the `envFile` option is deprecated, and the build reports an
  ineffective dynamic import of `PublicPageLayout`. None changes runtime
  behavior.

## Technical Debt

- `CanvasHandles` still commits text and image transform movement on every
  pointer move instead of once per gesture.
- GPU (PixiJS) and Three.js output have no visual tolerance strategy; golden
  fixtures cover Canvas 2D output.
- Nodes entry repairs overlapping cards after measuring them instead of
  reserving a collision-free layout for stored graphs up front.
