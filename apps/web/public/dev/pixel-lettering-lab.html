Pixel Lettering Lab

Type a line, pick a font, compare six ways to turn it into cell-grid lettering, then fix cells by hand. Prototype for Artifact issues #469 and #468.

Text

Grid

The grid is anchored to each line's start and baseline, so cap height always spans the same rows.

Algorithms

Dither pattern

Threshold drives Coverage, Outline, Dither and Rough. Stroke width drives Stroke and Outline.

Render

Cell shape

Chipped edges bite into exposed cell sides on square cells. Same seed, same bites.

Colours

Editor

Click or drag cells. Edits sit on top of the source algorithm, so switching the source keeps them. Changing rows or letter spacing moves the grid under them.
