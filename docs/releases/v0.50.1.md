# v0.50.1 Release Notes

Artifact v0.50.1 is the Editor Polish Patch release. The v0.50 editor now keeps
its promises: Nodes opens with every node readable, editor actions give visible
and truthful feedback, and Layers tree actions are reachable from a clicked
name, after Undo, and on touch.

This release fixes behaviour found by the 2026-10 editor polish audit without a
new visual direction. It does not replace menus, rows, headers, or controls,
does not redesign the mobile task flow, and does not add an export popover.

Document schema, graph traversal, renderer output, thumbnail scheduling, AI
scope, package export, and font policy remain unchanged. Entering Nodes now
stores placed node positions in the document, and image export reports its
result as described below; the preview, thumbnails, and exported images match
v0.50.0.

## Highlights

- Nodes opens readable
  ([#442](https://github.com/shchilkin/artifact/issues/442),
  [#461](https://github.com/shchilkin/artifact/pull/461)): nodes without a
  stored position are laid out before the first paint, cards that overlap are
  moved below the rest while cards that overlap nothing stay exactly where they
  were, and the graph is fitted once with no visible second fit. Placement adds
  no undo entry. Edit in Nodes selects and centers its target node. The Metrics
  and Debug toolbar controls appear only with `?debug` or `?perf=1`.
- Layers tree actions work where you expect
  ([#443](https://github.com/shchilkin/artifact/issues/443),
  [#459](https://github.com/shchilkin/artifact/pull/459)): Delete, arrow keys,
  F2, and Shift+F10 work after clicking a row's name. Undo, Redo, and inspector
  edits clear a stale tree status. The Layers inspector of a graph-only node
  offers Edit in Nodes. On touch, row actions stay visible and the handle,
  carets, folder controls, and actions button have 44 px hit areas.
- Inspector help and limits are reachable and honest
  ([#444](https://github.com/shchilkin/artifact/issues/444),
  [#460](https://github.com/shchilkin/artifact/pull/460)): effect help opens on
  click, Enter, or Space, closes on Escape, sits beside its row instead of over
  it, and is available on narrow screens. A typed value outside a slider's range
  shows the limit it was clamped to, such as "Max 100%". Effect descriptions
  name the real typed limits. The signed-out AI gate is a neutral notice with a
  Sign in action.
- The command bar holds still and export reports its result
  ([#445](https://github.com/shchilkin/artifact/issues/445),
  [#463](https://github.com/shchilkin/artifact/pull/463)): the undo-count badge
  moved into the Undo tooltip, so no command-bar button moves after the first
  edit. Export keeps a fixed width while it shows "Exporting…", announces the
  downloaded file name, and keeps an error visible with Retry, which repeats
  the export that failed. Destructive confirm dialogs use a filled danger
  button, and the Projects sheet says "Save current canvas" and "New blank
  canvas" with an icon Close button.
- Load, focus, error, and motion edges are fixed
  ([#446](https://github.com/shchilkin/artifact/issues/446),
  [#462](https://github.com/shchilkin/artifact/pull/462)): an unreadable `?doc`
  link says so and names the canvas shown instead, docs links say "Loaded from
  docs", and other links say "Opened from link". Hidden file inputs no longer
  take Tab stops. A canvas render error offers Undo and Retry and recovers
  without a reload. Sheets respect reduced motion, and the mobile viewport,
  theme color, and color scheme match the app surface.
- Editor strings are product copy
  ([#447](https://github.com/shchilkin/artifact/issues/447),
  [#458](https://github.com/shchilkin/artifact/pull/458)): internal notes and
  version labels are replaced with plain copy, in-progress labels end in "…",
  and a unit test keeps version strings and "..." out of user-facing copy.

## Scope Boundaries

- Included: audit group (a) only, the six delivery issues #442-#447 and their
  post-merge collision fix
  ([#464](https://github.com/shchilkin/artifact/pull/464)).
- Included: a new `command-bar/firstEditMovePx` editor UX budget of 0 px on
  desktop and mobile, enforced by `npm run ux:gate` with no exceptions.
- Included: the danger state color moved from `oklch(66% 0.18 28)` to
  `oklch(64% 0.19 14)` so it is distinguishable from the accent, and the shared
  UI package gained a `danger-filled` button variant and a popover anchor. No
  other token changed.
- Included: env-map export now reports an empty image as an error instead of
  silently downloading nothing.
- Deferred: one control grammar across menus, rows, headers, and controls is
  v0.51 Editor Polish.
- Deferred: the mobile task-flow layout (audit EP-33 to EP-35) stays in
  discovery, and an export popover is not part of this release.
- Deferred: compact placement of Nodes area frames, which can still overlap
  each other when an area's members end up far apart.

## Accepted Risks

- The Undo tooltip says "Cmd+Z" on every platform, including Windows and
  Linux, where the shortcut is Ctrl+Z.
- Entering Nodes writes placed positions into the document and its autosaved
  copy without an undo entry. Undoing to a snapshot from before an entry can
  bring back unplaced or overlapping positions; the next entry places them
  again.
- Nodes area frames follow their member nodes and can overlap each other after
  placement. Frames sit behind the cards, so every card stays clickable.
- Undo can merge a burst of numeric-entry edits on two fields with an edit made
  2.5 s earlier. This also happens in v0.50.0.
- The style guide (368.2 of 370 KiB) and Projects (221.1 of 230 KiB) remain
  close to their JavaScript budgets; the next route-level addition there needs a
  reviewed contract update.
- Grouping rows into a new merge, wiring side inputs, and creating fan-out
  remain available only in Nodes.

## Known Warnings

- The WebKit showcase-to-editor smoke (#435) passed without a retry in this
  run but needed one in v0.49.0 and v0.50.0, so it stays tracked.
- `npm audit` reports 3 advisories in transitive dependencies that were
  published after v0.50.0: `proxy-addr` (critical, through Express in the API
  and `@react-router/serve`), `compression` (high, through
  `@react-router/serve`), and `source-map-js` (high, through Vite, PostCSS, and
  Tailwind build tooling). This release does not change dependencies; the
  upgrade is tracked separately.
- React Router 7.18 prints v8 future-flag warnings during the build, Vite
  reports that the `envFile` option is deprecated, and the build reports an
  ineffective dynamic import of `PublicPageLayout`. None changes runtime
  behavior.

## Technical Debt

- Nodes entry repairs overlapping cards after measuring them instead of
  reserving a collision-free layout for stored graphs up front.
- The meta `theme-color` and manifest `theme_color` repeat the sRGB value of
  `--surface-app` because meta tags cannot read CSS variables; a browser test
  keeps them in agreement.
- `isEditableUndoTarget` in `useEditorDocument.ts` still has narrower semantics
  than the shared `isEditableKeyTarget` helper.
